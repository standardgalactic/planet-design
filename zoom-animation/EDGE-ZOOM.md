# Zoom with original-template edges

Replace your existing zoom.py with this version. Keep the old copy if you want to compare methods. The new options default to a locked border 12 percent of the image width and a further 12 percent feather transition. Use a new output folder because the generation settings have changed.

```bash
python zoom.py template.png \
  --prompt "futuristic coastal city, concrete terraces, curved glass, ocean mist, 1970s science fiction matte painting" \
  --frames 12 --zoom 1.06 --denoise 0.25 --cfg 4 \
  --edge-lock 0.12 --edge-feather 0.12 \
  --out zoom-output/edge-zoom-test
```

This zooms by 6 percent per AI step, a nominal total of 2.01x over 12 steps. It does not clean up, sharpen, match histograms, desaturate or globally recolor the generated image.

After every generation, a narrow outer border is taken from the ORIGINAL prepared template, cropped at the cumulative zoom for that step. It is not the same fixed border pasted onto every frame. The template border is therefore spatially aligned with the zoom. A smooth transition blends that border into the generated center. The center stays free to evolve under the prompt. The composited frame becomes the next img2img input.

This is a pixel-compositing constraint after generation, not a diffusion inpainting mask. It intentionally preserves actual source edge pixels rather than merely asking the prompt to retain their colors. A feathered but visible transition or portal-like effect can still occur if the center diverges greatly from the template. Only the retained border is constrained; central saturation and shape drift can continue. At deep zooms, the source border magnifies limited original pixels and may become soft.

--edge-lock is a fraction of the smaller dimension, measured inward from each side. --edge-feather is the additional transition width. Their sum must be below 0.5. Set --edge-lock 0 to disable the border constraint. The starting template is prepared as a center-cropped square, as in the earlier tool.

The animation still uses smooth crop-and-crossfade playback between AI frames, not optical flow. Its shared GIF palette can alter apparent colors even at protected edges. Inspect saved keyframe PNGs or the MP4 to assess source edge preservation before judging the GIF palette. Install ffmpeg to also obtain an MP4.

Use identical arguments to resume the new run. Existing pre-update runs use a different settings schema and should be kept in their old output folders. No images are generated by installing this update.
