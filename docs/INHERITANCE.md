# Inheritance and project identity

Planet Design is a fresh project directory derived from Steel Sky's working files. Copying without .git means that the new repository does not contain Steel Sky's 22,180-commit history. archdaemon is retained as a branch-name preference, not evidence of shared commit ancestry.

The earlier Steel Sky provenance documents, contributor records, Docker services and license remain available. PROVENANCE.md, provenance.csv, commits-over-time.csv and file-list.txt are inherited historical records and can become stale relative to this new working tree. None should be presented as a newly verified manifest of the planet project. This update does not modify or remove those records.

catalogue/, projects/01.01/, projects/03.01/ and the slate-samples manifests document a separate screenplay and image-pipeline programme. They are not planet lore, completed planet scripts or instructions used for the 137 new images. The four Ankara WebP files are historical previews and are omitted from the new gallery.

The new primary record is README.md, docs/PROCESS.md, docs/PROMPTS.md and manifests/planet-design.json. The actual images remain in the existing root, locations/ and world-expansion/ paths. The gallery can recover PNG metadata but does not establish authorship or licensing from metadata alone.
